# Task 3: Complete Agent Communication Workflow

## Objective
Demonstrate the complete workflow for communicating with an Azure AI agent. This comprehensive task includes:
1. **Start Conversation** - Create a new conversation thread with the agent
2. **Send Message** - Send a message to the agent and receive a response
3. **Process Response** - Extract text content and identify any files/charts in the response
4. **Get Conversation History** - Retrieve the complete conversation history including both user and agent messages
5. **Handle File Content (optional)** - Download and save any files returned by the agent

This task encompasses the entire agent interaction lifecycle from initialization to file handling.
