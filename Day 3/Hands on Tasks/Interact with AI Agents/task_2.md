# Task 2: Create an Agent Programmatically

## Objective
Learn how to create and configure an AI agent programmatically using the Azure AI Projects SDK. This task demonstrates:
- Creating an agent with specific model and instructions
- Configuring agent properties (name, description, tools)
- Retrieving agent details
- Cleaning up by deleting the agent when done

This is essential for understanding how to dynamically create agents with custom configurations.
