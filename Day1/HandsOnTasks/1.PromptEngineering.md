# Prompt Engineering Lab

## Overview
This lab helps you understand how different system and user prompts can produce different outcomes from the same conversation transcript. You'll learn how to craft effective prompts to extract specific information, generate summaries, ensure compliance, and provide quality feedback.

## Conversation Transcript

```
Agent: Hello, thank you for calling the Contoso bank. How may I help you?
Customer: Yes, I lost my debit card, so I'm calling to get a new debit card and block the one that I lost so nobody can use it.
Agent: Sure, I can help you with that. Do you happen to have your account number?
Customer: No, I don't.
Agent: OK, let's start with your name.
Customer: Yes, my name is John Smith.
Agent: And can I have your phone number please?
Customer: It's 312-847-9299.
Agent: OK, and for verification, can you give last four digits of Social Security number?
Customer: Sure, it's 1222.
Agent: OK, and what is your mailing address?
Customer: It's 2030 S Michigan Ave. Chicago IL 60616.
Agent: OK. Thank you for verifying your details.
Agent: I am going to block your current debit card so no one can use that. And I'm also going to mail you a new debit card at your mailing address. Is there anything else I can help you with?
Customer: Yes, is it possible for you to also send me my bank statement so I can see if there are any unauthorized charges?
Agent: Yes, I can do that. You'll be getting that statement in three to five business days. Anything else I can help you with?
Customer: No, thank you.
```

## Prompt Engineering Exercise

Try different combinations of system and user prompts to achieve various outcomes. Below are examples of different prompt strategies:

## Instructions for Lab Exercise

1. **Choose a Scenario**: Select one of the prompt combinations from the table above.

2. **Set the System Prompt**: Configure your AI model with the system prompt (right column).

3. **Provide the User Prompt**: Send the custom prompt (left column) along with the conversation transcript.

4. **Observe the Results**: Notice how different prompts yield different types of outputs:
   - General summaries vs. focused summaries
   - Plain text vs. structured JSON
   - Factual extraction vs. analytical feedback

5. **Experiment**: Try modifying the prompts to:
   - Extract different fields
   - Change the output format
   - Add or remove constraints (like PII handling)
   - Adjust the tone or perspective

## Key Learning Points

- **System prompts** set the role, context, and constraints for the AI
- **User prompts** provide specific instructions and the data to process
- **Structured prompts** (with specific keys/format) produce more consistent, machine-readable outputs
- **Role-based prompts** (compliance officer, supervisor) change the analysis perspective
- **Explicit constraints** (e.g., "do not include PII") help with privacy and compliance
