# Azure AI Foundry: Add Code Interpreter to an Agent

This guide walks you through creating and testing an Agent in Azure AI Foundry (ai.azure.com) directly in the portal, then shows where to find connection details to use it from code.

## Prerequisites
- Azure subscription with access to Azure AI Foundry (formerly Azure AI Studio).
- An Azure AI Foundry Project you can create resources in.
- At least one model available 


## 1) Open Azure AI Foundry and select your Project
1. Go to https://portal.azure.com and sign in.
2. Pick your Project:
   - If creating a new Project: choose name, region, and resource group.

## 2) Create a new Agent
1. In the Project left navigation, select **Agents**.
2. Click **+ New agent**.

## 3) Agent Setup
1. Select a model deployment to use from the dropdown **Deployment** selector on the right.
2. Give your agent a name by chaning the default provided in the **Agent name** field.
3. Give you agent the following **Instructions**: 

"Role & Mission
You are a helpful assistant very good at writing code to analyze documents. A single file has been uploaded which has student loan guidelines. 

Hard rules
The user is NOT technical, do not show them any code.
Follow the Workflow step-by-step, in order. 
Only look at the uploaded file. 

Workflow
1) Look at the user's message and make sure they provide a "Section Keyword" to look for in the uploaded document. 

2) If there is no keyword provided, please tell them to make sure to provide a keyword and give the following samples "Purpose & Background, Undue Hardship Evaluation Framework,  Present Ability to Pay". 

3) If the user provides a "Section Keyword" write code to find and return all the content of that section. 

4) If the section is not found, reply "Section not found". "


## 4) Save and Test
1. The agent should autosave but scroll to the bottom of the Setup panel and click the save icon to ensure the agent is updated. 
2. Scroll to the top of the Setup panel and click "Try in playground"
3. Ask the agent a simple quesiton like "Hello, how are you today?" and look at the response. Note how the agent did not see the section keyword and replied accordingly.
4. Click the "Thread logs" button to view the details of the execution.
5. Click the "View code" button to view the code to use the agent programatically. 
## 5) Upload the provided data 
1. Uploaded the provided data file named "Student_Loan_Federal_vs_Private_Guide" by clicking the "Message files" paperclip icon at the bottom. Select the '+Add' button next to code interpreter and upload the file to give the agent access to that file.
2. Ask the Agent the following: "Please find the Section Purpose & Background"
2a. If the agent asks a clarifying question, reply appropriately (e.g., should I only look for an exact match) but make sure you re-upload the file.
3. View the results as before but notice the the "Tool" elements in the execution.

## Tips and best practices
- **Precise Instructions**: Be explicit about goals, style, and constraints. Make sure you're very concrete in your replies and do not make any assumptions. 
- **Uploaded Data**: Upload the data as part of the message to ensure the agent can access the content.
