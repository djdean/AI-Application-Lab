# Test Your Index in Microsoft Foundry Playground

## Overview

This lab guides you through testing your Azure AI Search index using the **Playground Chat** in Microsoft Foundry. This is a quick way to validate your index is working before creating a persistent agent.

> 📋 **Prerequisite**: Complete the [Creating AI Search Index in Portal](CreatingAISearchInPortal.md) lab first.

---

## Step 1: Verify Indexer Status

Before testing, ensure your indexer has completed successfully:

1. In Azure AI Search, go to **Indexers**
2. Check that your indexer shows **Success** status
3. Note the number of documents processed

> ⚠️ If the indexer shows errors, check the execution history for details.

---

## Step 2: Open Microsoft Foundry Playground

1. Navigate to [Microsoft Foundry Portal](https://ai.azure.com)
2. Select your project
3. Go to **Playgrounds** → **Chat**

---

## Step 3: Connect Your Index

1. In the Chat Playground, click **Add your data**
2. Select **Azure AI Search** as the data source
3. Choose your search service and index created in the previous lab
4. Configure search settings:

| Setting | Recommended Value |
|---------|-------------------|
| **Search type** | Hybrid |
| **Top K** | 3-5 results |
| **Semantic ranking** | Enabled (if available) |

---

## Step 4: Test with Questions

Ask questions about your indexed documents:

```
Example queries:
- "What is this document about?"
- "Summarize the key points"
- "What are the main requirements mentioned?"
- "List the steps described in the document"
```

---

## Step 5: Verify Grounded Responses

When testing, check for:

- ✅ Responses include **citations** from your documents
- ✅ Agent references the correct content
- ✅ Answers are factually accurate based on your data
- ✅ Different question types return relevant results

### What to Look For

| Good Response | Poor Response |
|---------------|---------------|
| Includes document citations | No citations or references |
| Answers match document content | Generic or hallucinated content |
| Specific details from your data | Vague or incorrect information |

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| No results returned | Verify indexer completed, check document count |
| Irrelevant results | Try hybrid search, enable semantic ranking |
| Missing citations | Ensure index has content fields mapped correctly |
| Slow responses | Reduce Top K, check index size |
