# Using AI Search Index with Microsoft Foundry Agent

## Overview

This lab guides you through connecting your Azure AI Search index to a **Microsoft Foundry Agent** for RAG-powered conversations.

> 📋 **Prerequisite**: Complete the [Creating AI Search Index in Portal](CreatingAISearchInPortal.md) lab first.

---

## Why Use Foundry Agent with AI Search?

- **Knowledge-grounded responses**: Agent retrieves relevant documents before generating answers
- **Reduced hallucination**: Responses are based on your actual data
- **Enterprise-ready**: Combines Azure AI Search with Azure OpenAI

---

## How It Works

```
User Query → Foundry Agent → AI Search Index → Retrieve Documents → Generate Response
```

1. User asks a question
2. Agent searches the index for relevant chunks
3. Retrieved content is added to the prompt context
4. Agent generates an accurate, grounded response

---

## Step-by-Step: Connect Agent to AI Search Index

### Step 1: Navigate to Microsoft Foundry

1. Go to [Microsoft Foundry Portal](https://ai.azure.com)
2. Select your project

### Step 2: Create or Open an Agent

1. Navigate to **Agents** in the left menu
2. Create a new agent or open an existing one

### Step 3: Add Knowledge Source

1. In the agent configuration, find **Knowledge** or **Data sources**
2. Click **Add data source**
3. Select **Azure AI Search**

### Step 4: Configure AI Search Connection

| Field | Value |
|-------|-------|
| **Search service** | Select your Azure AI Search resource |
| **Index** | Select the index created in the previous lab |
| **Authentication** | API Key or Managed Identity |

### Step 5: Configure Search Settings

- **Search type**: Hybrid (recommended) or Vector
- **Top K results**: 3-5 (number of chunks to retrieve)
- **Semantic ranking**: Enable for better relevance

### Step 6: Test the Agent

1. Open the chat interface
2. Ask questions about your indexed documents
3. Verify the agent retrieves and references the correct content

---

## Example Queries

Try asking your agent questions related to your indexed documents:

- "What are the main topics covered in the documents?"
- "Summarize the key points about [specific topic]"
- "What does the document say about [specific detail]?"

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Agent doesn't find relevant content | Check if indexer completed successfully |
| Poor quality answers | Enable semantic ranking, adjust Top K |
| No results returned | Verify index has documents, check search permissions |
